# Jungle Adventure

A 2D side-scrolling jungle platformer by **AniX Creations**, built with HTML, CSS, JavaScript and Phaser 3.

## Run locally

1. Open this repository in Visual Studio Code.
2. Install the **Live Server** extension.
3. Open `index.html`.
4. Right-click and choose **Open with Live Server**.

No Node.js installation or build step is required. Phaser 3 is loaded from jsDelivr.

## Controls

| Key | Action |
| --- | --- |
| Left Arrow / A | Move left |
| Right Arrow / D | Move right |
| Space / Up Arrow / W | Jump |

## Current build

- Side-scrolling camera that follows the player
- Jungle background and platform course
- Keyboard movement and jumping
- Collectible gems and score counter
- First trail with an end marker

The player and environment currently use generated placeholder graphics. Animated character artwork, improved level design, enemies, sound and touch controls will be added in later stages.
